name: ponytail-help
description: Explain Ponytail modes and available project skills.
---

Ponytail defaults to **full**: smallest complete change, test non-trivial logic and state risks. **lite** builds the request and notes the smaller option. **ultra** challenges unjustified scope before implementation. Use **ponytail-review** to review a diff and **ponytail-audit** to audit the repository. Stop or switch modes when the user asks.
